# Uniswap V2 from Scratch

An educational project rebuilding Uniswap V2 from scratch using **Solidity 0.8.35** and **Foundry**.

I created this repository to document what I am learning at [Zealynx Academy](https://academy.zealynx.io/) and deepen my understanding of how Uniswap V2 works.

## Differences from the Original

The original Uniswap V2 core contracts use Solidity 0.5.16 and the SafeMath library for checked arithmetic. This project uses Solidity 0.8.35, which reverts on arithmetic overflow and underflow by default, so SafeMath is unnecessary for checked addition, subtraction, and multiplication.
